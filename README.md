# Santander Dev Week 2023 - ETL com Python

Este projeto implementa um pipeline ETL simples:
- **Extract:** leitura de IDs de usuários a partir de um CSV.
- **Transform:** geração de mensagens personalizadas de marketing.
- **Load:** atualização dos dados em uma API ou salvamento em CSV.

Ferramentas utilizadas: Google Colab, Pandas, Requests.
